# 课间 · Lecture Atlas

把一节课的 **PPT/PDF、课堂转录与录音** 连成可以回溯的知识导图。第一版为个人使用的中文网页工作台。

## 已实现

- 导入 PDF / PPTX；PDF 原页预览与逐页文字提取，PPTX 按演示顺序提取文字。
- 导入录音与 SRT / VTT 字幕，保留原始时间戳。
- 无 API 密钥时，生成明确标注的**本地逐页摘录和词语匹配目录**，并可浏览自制示例。它不是 AI 总结。
- 配置 OpenAI 后：带时间戳语音转录、结构化知识导图、重点识别、课件与课堂原文中英翻译。
- 点击知识点联动课件页；点击课堂切片定位录音并在片段结束时暂停。
- 区分老师强调、重复讲解与 AI 建议关注；显示来源和匹配置信度，可手动校正。
- 课程、原课件与录音保存在当前浏览器 IndexedDB。刷新可恢复，多个课次独立保存。
- 导出 Markdown 或 JSON 笔记。提供自制 PDF、PPTX、SRT 测试资料。

## 本地启动

需要 Node.js 22.13+（建议 Node.js 24）。

```bash
npm ci
npm run dev
```

打开终端显示的本机地址，默认是 `http://127.0.0.1:5173`。若端口被占用：

```bash
npm run dev -- --port 5187
```

首次打开为**自制示例课**，示例没有真实课堂录音。选择“导入本节资料”创建自己的课次；可下载导入窗口底部的测试课件与字幕。

## 启用 AI（可选）

```bash
cp .env.example .env
```

在 `.env` 中填写自己的 `OPENAI_API_KEY` 并重启。`OPENAI_TEXT_MODEL` 默认 `gpt-4o-mini`，可换为支持 Responses API 严格 JSON Schema 输出的模型。转录固定使用支持分段时间戳的 `whisper-1`。

密钥只在服务端使用，页面不接受或保存 API 密钥。“AI 设置”只显示配置状态；已配置不代表密钥已通过付费调用验证。API 由 OpenAI 单独计费。

**数据边界：**普通导入/阅读/本地目录不发送文件到 AI。点击“AI 整理本节课”时，课件提取文字、现有字幕会发送到 OpenAI；没有字幕且有录音时，录音也会发送用于转录。翻译仅发送选中的文字。Responses 请求设置 `store:false`，服务商其他保留策略请自行查阅官方说明。

## 检查与构建

```bash
npm run typecheck
npm test
npm run build
npm start
```

测试覆盖字幕时间、否定/历史考点语句、错误来源引用、导出出处等。没有 API 密钥时可运行全部本地测试，但不能据此声称真实模型质量已经验证。

前端为 React / TypeScript，路由和服务端采用 Vinext / Vite，构建为 Cloudflare Worker 兼容输出；组件采用已有 Shadcn / Radix，文件解析使用 PDF.js 和 fflate。开发依赖中的 PDF.js 资源由启动/构建脚本复制到忽略目录，无需另行下载。

`npm start` 是本地生产构建预览，不会把站点发布到公网。若以后远程部署，需要配置 `LECTURE_ACCESS_TOKEN`，页面中输入对应访问口令；API 会拒绝没有口令保护的非本机调用。此版本面向个人原型，不包含多用户身份、共享存储或分布式限流。正式服务需补充这些能力。

## 当前限制

- 课件单文件 ≤30 MB、≤160 页。旧 `.ppt` 先另存为 PPTX 或 PDF。
- PPTX 只显示文字，不还原图片、图表和原始排版。PDF 扫描页目前不做 OCR，可能只能看原页。复杂公式可能提取不完整。
- 音频单文件 ≤24 MB。超过限制请压缩为 MP3 或按课次拆分；自动分块与后台队列留待下一版。
- 字幕 ≤2 MB、≤3000 条；AI 请求总文本约 ≤600 KB，超限时明确报错，不静默截断。
- 仅支持**导入后的音频时间轴**，没有学校播放器跳转或实时标签页录音。
- 本地匹配是词语重合启发式，可能有误；AI 推断也不等于考试承诺。
- 译文在页面中对照显示，不导出还原排版的英文/中文 PPT。
- JSON 为数据导出，尚无重新导入入口。清除浏览器数据会清空课程；请保留原始课件与录音并导出笔记。
- AI、真实课堂识别质量和 WebMCP 浏览器支持需在具备相应条件后另行验证。

## 项目结构

- `app/page.tsx`：课堂工作台和资料导入。
- `app/api/`：配置状态、转录、结构化总结、翻译接口。
- `lib/documents.ts`：PDF / PPTX 解析。
- `lib/learning.ts`：字幕解析、本地目录、重点规则、笔记导出。
- `lib/validation.ts`：结构与来源校验。
- `lib/storage.ts`：当前设备 IndexedDB 资料库。
- `tests/`：核心逻辑检查。
- `docs/PLAN.md`：版本范围与后续计划。
