- 预置第一版 IndexedDB，升级后保留原课程。
- 导入自制 PDF，采集三个独立音频分段；每段均可实际解码和播放。
- 持有浏览器任务锁时，另一次转录请求被拒绝且未上传音频；释放后可正常重试。
- 模拟第二段转录返回错误；刷新页面后继续转录，总请求数为分段数 + 一次失败，成功的第一段没有重复上传。
- 将结果应用到课堂，点击第二段字幕后播放器选中第二个文件，按切片结束时间停止。
- 再次刷新仍能读取分段音频和整课转录；390px 手机宽度无横向溢出，页面无 JavaScript 未捕获异常。
