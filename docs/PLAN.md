# 课间 · 第一版范围

目标：一节课的课件、转录与录音通过知识点连接；每个结果都有可回溯的出处。

## 第一版
- PDF 原页预览、文字提取；PPTX 按演示顺序提取文字（不承诺还原原始版式）。旧 .ppt 需先导出 PDF。
- 音频导入和播放；SRT/VTT 导入；有服务端 API 密钥后调用带时间戳的转录。
- 无密钥：本地逐页摘录与词语匹配目录，明确标记为本地整理，匹配置信度低时不自动绑定。
- 有密钥：结构化知识节点、章分类、来源页码、转录片段引用、重点分类、双语翻译。
- 点击节点切换课件页；选择录音片段定位播放；支持手工校正片段对应页。
- 当前设备 IndexedDB 保存课程文本和原始资料，支持 Markdown / JSON 导出。
- 明确区分示例、规则摘录、AI 结果。

## 下一版
实时标签页音频采集、长录音任务队列与自动分块、OCR、复杂图表公式识别、学校账号连接、跨课次复习与自测。

## 核心验收
1. 示例课的四个节点可定位四页，原话可追溯。
2. 两个新课程的数据互不混合；刷新后可恢复当前设备的资料。
3. SRT/VTT 时间正确，无效字幕不生成虚构时间。
4. AI 返回的未知页码与片段 ID 被拒绝；低置信度不当作确定匹配。
5. 没有密钥时，转录与翻译返回明确配置说明。
6. 密钥不会返回到前端、日志、导出或 Git 仓库。
7. 导入错误保留已有课程，上传限制可见。
