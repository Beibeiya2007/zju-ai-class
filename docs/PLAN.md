# 课间 · 产品路线

目标：把课程课件、转录与录音连接成可回溯、便于复习的学习记录。

## 第一版（已完成）

- PDF 原页预览和文字提取；PPTX 按演示顺序提取文字。
- 录音、SRT/VTT 导入；可配置 AI 生成带时间戳的转录与知识目录。
- 知识点跳转课件页，课堂切片定位录音；来源可手动校正。
- 无 API 密钥时提供本地整理；课程保存在当前设备并可导出。

## 第二版（已完成）

- 浏览器麦克风录音和共享课堂回放标签页音频，仅录音频轨道，不录屏。
- 停止后先试听和下载，再保存到选定课次；替换旧录音时提醒清空不匹配字幕。
- 录音超过约 22 MB 自动停止；最长 90 分钟；单文件保存和 AI 转录接口上限 24 MB。
- 多课次复习队列，可按待复习、重点候选、困难项、课程和关键词筛选。
- 先回忆、后显示知识笔记及来源；自评结果保存在当前设备。掌握后按 1/3/7/14 天复习，困难项隔日复习，忘记时 10 分钟后重试。
- 复习记录绑定当前知识点和出处内容；资料修订后自动失效，避免旧掌握状态误导。

## 第三版（已完成）

- 长课堂采集约每分钟形成一个完整音频文件并保存至 IndexedDB，最长 4 小时 / 500 MB。
- 本地转录队列按段上传，记录成功/失败/中断；用户可暂停、重试，刷新后继续处理尚未完成的分段。
- 使用 Web Locks 避免同时打开多个标签页重复处理；保存失败保留当前片段供下载/重试。
- 转录以独立分段为来源，合并时转换到整节课时间；间隙不绑定虚假音频。
- 整合到原课堂播放器：支持选择分段、连续回放和知识点切片跳转。
- 本地资料库从 v1 升至 v2，保留原有课程；恢复已保存的录音，不承诺恢复退出前未完成的片段。

## 后续阶段

- 已有长音频文件的自动切分、服务器后台任务；目前页面关闭后队列会停止，下次打开可手动继续。
- OCR、公式与复杂图表识别。
- 学校账号/课程资料接入。需先确认身份验证授权、Cookie/凭据边界、校方规则和接口稳定性，再接入只读课程资料。
- 复习日历、错题回顾和真实课堂转录效果评估。

## 安全与边界

- 浏览器标签页音频支持取决于浏览器和共享选择，系统授权不能保证一定有音轨；麦克风是备用方式。
- 录音只采集音频，不录屏；明确展示试听、下载和保存操作。本地录制目前要求当前页面保持打开。
- 无 AI API 密钥时，课堂转写、AI 总结与翻译不可用；本地提取/关键词目录不是 AI 总结。
- 学校账号保持独立后续阶段，本版本不存储学号/密码，不使用或复制参考仓库代码。
